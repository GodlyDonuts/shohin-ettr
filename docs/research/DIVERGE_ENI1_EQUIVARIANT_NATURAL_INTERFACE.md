# DIVERGE-ENI1: Equivariant Natural Interface

Status: frozen after EIC1 confirmation and before ENI1 model scoring.

## Capability hypothesis

STI1 failed because its RRG1 QUERY owner learned one held-renderer role
inversion. EIC1 changes that exact computation boundary and confirms
`768/768` normal plus mapped-swap accuracy on a source-disjoint board. NVE1
already owns the natural EVIDENCE transaction exactly, while the NPL1 WORLD
surface has an independently checked structural parser.

ENI1 tests one narrow composition claim:

> The confirmed EIC1 QUERY owner can replace STI1's failed RRG1 QUERY owner
> on the existing source-disjoint natural mini-language while protected NVE1
> EVIDENCE and structural WORLD ownership remain exact.

There is no training, adapter change, prompt change, renderer change, or PL1
write in ENI1. It is an interface-compatibility gate before one end-to-end
natural verified-plasticity run.

## Frozen development gate

All conditions are conjunctive:

1. structural WORLD parsing is `7,168/7,168`;
2. NVE1 EVIDENCE joint-role accuracy is at least 99.5% aggregate and 99% on
   every renderer;
3. EIC1 QUERY accuracy is at least 99.5% aggregate and 99% on every renderer;
4. mapped mention-swap QUERY accuracy satisfies the same floors;
5. source scrub loses at least 40 points and has absolute mean signed margin
   at most `1e-9`;
6. entity-renamed prompts, predictions, and scores are bit-exact;
7. the involution identity residual is exactly zero; and
8. EIC1 and protected STI/NVE1 owner hashes remain exact.

A pass admits exactly one DIVERGE-NPL2 natural verified-plasticity
integration, using the existing PL1 update rule unchanged. A miss closes this
composition without EIC width, layer, duration, prompt, renderer, threshold,
or seed variants. ENI1 is not itself a reasoning result and does not authorize
continuation pretraining.
